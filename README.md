# UNICON FF–PID 휠체어 Android 앱

## 소개 및 변경 사항

한양대학교 UNICON Lab의 **FF–PID 기반 전동휠체어 자율주행 시스템**을 운용하기 위한 Android 앱입니다.

기존 Android 앱의 구조와 일부 기능을 활용하면서, **FF–PID 주행 코드에 맞게 앱 화면과 READY·주행 제어 기능을 수정·추가**했습니다. NUC와 앱을 연결하는 **Bluetooth 브릿지는 FF–PID 전용으로 새로 개발**했습니다.

주요 기능:
- NUC Bluetooth 연결, READY 시작·종료
- READY 단계·센서 상태·실패 원인 모니터링
- LiDAR·IMU 연결 테스트
- 6개 경로 선택, 주행 시작·종료
- 출발 위치 및 방향 검사, 출발 거부 이유 안내
- 주행 상태와 Safety 감속·정지 사유 표시
- 주행 종료 오류 발생 시 정지 상태 재검증
- 선택 경로 선 및 현재 휠체어 위치·방향 표시

## 사용 전 주의사항

**버튼을 누르면 작업이 완료되거나 결과가 표시될 때까지 기다려 주세요. 기다리는 동안 다른 버튼을 연속해서 누르지 마세요.**

- LiDAR와 NUC 전원, 바퀴 전원을 연결하고 조이스틱 표시등 및 LiDAR 동작을 확인합니다.
- READY 시작이나 주행 시작을 요청할 때 휠체어는 정지해 있어야 합니다.
- 최초 READY는 가능하면 **애지문 출발 지점**에서 진행합니다. 다른 위치에서는 초기 위치 정합이 실패할 수 있습니다.
- NUC를 재부팅했다면 Bluetooth 연결과 READY를 다시 진행합니다.
- **앱의 주행 종료는 물리적 비상정지가 아닙니다.** 위험할 때는 휠체어의 물리적 정지 수단으로 안전을 확보해 주세요.

## 관리자 화면: 각 버튼 설명

### NUC 연결

스마트폰과 NUC를 **Bluetooth**로 연결합니다.

스마트폰 Bluetooth 설정에서 먼저 NUC와 페어링한 다음 앱의 **NUC 연결**을 누릅니다. 화면에 연결 상태가 표시됩니다. 연결이 안 되면 Bluetooth 페어링과 NUC 전원·배터리 상태를 확인합니다.

### READY 시작

자율주행에 필요한 센서, 위치추정, 장애물 인식 및 구동계 통신을 시작하고 검사합니다.

**READY 시작**을 누른 뒤 아래의 **READY 상태**와 **READY 실행 기록**을 보면서 완료될 때까지 기다립니다. 성공하면 'READY 준비 완료'로 표시됩니다. 정상적으로 READY를 실행했다면 경로를 바꿀 때마다 다시 실행할 필요는 없습니다.

관리자 화면의 상태 항목:

| 항목 | 확인 내용 |
| --- | --- |
| LiDAR / IMU | 센서 데이터가 들어오는지 |
| FAST-LIO | LiDAR 기반 위치추정이 동작하는지 |
| 지도 위치추정 / GICP 진단 | 지도와 현재 위치의 정합·추정 상태 |
| 장애물 인식 | 주변 장애물 인식 정보가 들어오는지 |
| GICP 제외 영역 | 위치추정용 제외 영역 관련 상태 |
| 바퀴 상태 | 휠체어 구동부 상태를 수신하는지 |
| UART 진단 | NUC와 구동부 간 통신 상태 |

'정상 수신', '수신 대기 중', '데이터 수신 안 됨', '실패' 등이 표시됩니다. READY 실패 시 아래 실행 기록의 실패 원인을 먼저 확인합니다.

### READY 종료

자율주행 관련 READY 시스템을 종료합니다. **모든 주행과 실험이 끝났을 때** 사용합니다. 주행 중이었다면 먼저 **주행 종료**로 정차·종료를 확인한 후 진행합니다.

### LiDAR 연결 테스트 — READY 실패 시 사용

READY가 실패했고 **LiDAR 또는 IMU 신호가 안 들어올 때** 사용하는 기능입니다.

1. READY가 실행 중이라면 해당 작업이 정리되었는지 확인한 뒤 **테스트 시작**을 누릅니다.
2. 화면의 **ROS Master / Livox 드라이버 / LiDAR / IMU** 상태를 봅니다.
3. **현장에서는 LiDAR 전원 커넥터의 접촉 문제로 신호가 안 들어오는 경우가 있었습니다.** LiDAR 전원선을 뺐다가 다시 꽂고, 커넥터의 꽂힌 방향이나 위치를 조금씩 돌려 조정하면서 **LiDAR가 실제로 켜지고 LiDAR·IMU가 모두 '정상 수신'으로 바뀔 때까지** 상태를 확인합니다. 한 번에 안 되면 재연결과 접촉 위치 조정을 몇 차례 반복해야 할 수 있습니다.
4. 양쪽 신호가 정상적으로 들어오면 **테스트 종료**를 누르고 종료가 완료될 때까지 기다립니다.
5. 이후 **READY 시작**을 다시 누릅니다.

**테스트 종료 후 READY는 자동 시작되지 않습니다.** 전원 커넥터를 강하게 비틀거나 손상된 케이블을 계속 사용하지 마세요. 접촉 상태가 불안정하다면 연결부 점검·수리가 필요합니다.

LiDAR와 IMU가 정상인데 GICP 단계에서 실패한다면 출발 위치, 주변에 지나가는 사람, LiDAR를 가리는 물체 등을 확인하고 READY를 다시 시도합니다.

## 탑승자 화면: 각 버튼 설명

### 경로 선택

탑승자 화면 오른쪽의 **경로 선택**에서 원하는 경로를 고릅니다. 현재 지원 경로는 6개입니다.

- 애지문(2번 출구) → 정몽구센터
- 애지문(2번 출구) → 2공학관
- 정몽구센터 → 애지문(2번 출구)
- 정몽구센터 → 2공학관
- 2공학관 → 애지문(2번 출구)
- 2공학관 → 정몽구센터

아래 지도에는 **선택한 경로 선과 출발·도착 지점, 현재 위치·방향(수신되는 경우)**이 표시됩니다. **아직 건물이나 도로가 보이는 배경 지도 이미지는 없고 경로 선 위주로 표시됩니다.**

### 주행 시작

READY가 완료되고 휠체어가 **수동 조작 모드**인 상태에서, 경로를 선택한 후 **주행 시작**을 누릅니다.

시작 전에 경로와의 거리·방향을 확인합니다. 경로에서 너무 멀거나 방향이 맞지 않으면 출발이 거부되고, 아래 **주행 상태 및 안내**에 조정 방법이 표시됩니다. 안내를 보고 조이스틱으로 위치·방향을 맞춘 뒤 다시 시도합니다. 출발 검사 기준은 대략 **경로까지 1m 이내, 방향 오차 30° 이내**이며 최종 판단은 NUC가 합니다.

앞에 사람이 지나가거나 출발 위치 주변에 장애물이 있어 실패한 경우에는 주변이 정리된 뒤 다시 시도하면 됩니다.

### 주행 종료 — 언제 눌러야 하나요?

**한 번의 주행을 마무리한 뒤 다음 주행을 하려면 '주행 종료'를 먼저 눌러야 합니다.** 아래 상황에 해당합니다.

- **목적지에 도착했을 때**
- **조이스틱을 사용하여 수동 조작으로 전환했을 때**
- **다른 경로를 선택하여 다시 출발하려 할 때**
- **주행이 중단되었거나 새로 시작해야 할 때**

예를 들어 '애지문 → 2공학관'을 마친 뒤 '2공학관 → 애지문'으로 돌아가려면 **주행 종료 → 종료 완료 확인 → 새 경로 선택 → 필요하면 위치·방향 조정 → 주행 시작** 순서입니다.

**주행 종료를 눌러도 READY는 유지됩니다.** 다음 주행을 위해 READY를 다시 시작할 필요는 없습니다.

단, 주행 중 사람이 지나가 Safety가 잠깐 **STOP**이 된 것은 '주행 종료'와 다릅니다. 장애물이 사라져 안전 조건이 회복되면 시스템이 자동으로 재출발할 수 있으므로, 잠깐 멈출 때마다 주행 종료를 누를 필요는 없습니다.

### 정지 상태 재검증 — 주행 종료 오류 시 사용

주행 종료 후 다음 출발이 거부되거나 **'주행 종료 실패', '정지 확인 실패', 'STOP_UNVERIFIED'** 등의 안내가 나올 때 사용합니다.

1. **실제로 바퀴가 멈춰 있고 수동 조작 모드인지 먼저 확인**합니다.
2. **정지 상태 재검증**을 한 번 누릅니다.
3. 버튼을 누른 뒤 바로 또 누르지 말고 **검증 결과가 나올 때까지 기다립니다.**
4. 검증에 실패해도 휠체어가 정지 상태라면 **다시 눌러 재시도**합니다. 현장에서는 몇 번 재검증을 반복한 뒤 정상 처리되는 경우도 있었습니다.
5. **검증 완료**가 표시되면 주행 시작을 다시 누릅니다.

반복해도 실패하면 계속 누르기보다는 화면의 거부 사유를 확인합니다. **재검증은 바퀴를 멈추는 버튼이 아니라, 이미 정차했는지 확인하고 이전 주행 상태를 정리하는 기능**입니다.

## 화면의 상태·안내문 보는 법

### 관리자: READY 상태 및 실행 기록

READY의 각 단계가 정상인지, 어느 센서나 프로세스에서 문제가 생겼는지 표시합니다. 실패했을 때는 **READY 실행 기록**과 실패 사유를 확인합니다.

### 탑승자: 주행 상태 및 안내

- **현재 모드:** '수동 조작 모드 (조종간)', '자율주행 모드', '확인 불가' 중 현재 휠체어 모드
- **주행 안내문:** 출발 조건 검사, 위치·방향 조정, 주행 시작·거부, 목적지 도착, 수동 개입, 주행 종료 및 재검증 결과
- **Safety 상태:** 현재 속도 제한·안전 정지 판단
- **Safety 사유:** 왜 감속하거나 멈췄는지에 대한 설명

| Safety 표시 | 의미 |
| --- | --- |
| CLEAR | 정상 주행 가능 |
| SLOW | 감속 중 |
| STOP | 안전상의 이유로 정지 중 |
| 확인 불가 | 현재 유효한 Safety 정보가 없거나 통신·상태 확인이 어려움 |

예를 들어 진행 경로의 장애물, 과속방지턱, 목적지 접근, 곡선 구간, 경로 이탈, 위치추정 이상, 우회 경로 처리 등이 감속·정지 사유로 표시될 수 있습니다.

**Bluetooth 연결이 끊겼거나 상태가 '확인 불가'라면 앱 표시만 보고 정차했다고 판단하지 마세요.**

## 자주 발생하는 문제

| 상황 | 현장 조치 |
| --- | --- |
| NUC 연결 실패 | Bluetooth 페어링, NUC 전원 및 배터리 확인 |
| READY 실패: LiDAR·IMU 신호 없음 | LiDAR 연결 테스트 실행 후 전원선 재연결·커넥터 위치 조정, 정상 수신 확인 |
| READY 실패: GICP 정합 실패 | 초기 위치, 주변 사람·장애물, LiDAR 가림 여부 확인 |
| 주행 시작 거부 | 화면 안내에 따라 경로와의 거리·방향 조정 후 재시도 |
| 사람이나 장애물 때문에 출발 실패 | 주변 공간 확보 후 다시 시작 |
| 목적지 도착 후 다음 경로 시작 불가 | 주행 종료 완료 확인 후 경로 변경·주행 시작 |
| 수동 조작 전환 후 재출발 불가 | 주행 종료 후 재출발 |
| 정지 확인 실패 / STOP_UNVERIFIED | 실제 정지·수동 모드 확인 → 재검증 → 결과를 기다린 뒤 필요 시 몇 차례 재시도 |
| 주행 중 Bluetooth 연결 끊김 | 앱에서 정지 명령이 전달되지 않을 수 있으므로 물리적 정지 수단으로 안전 확보 |

## 참고

- **버튼을 누르면 결과가 나올 때까지 기다리고 다른 버튼을 누르지 마세요.**
- **주행 종료**와 **READY 종료**, 장애물에 의한 일시적인 **Safety STOP**은 서로 다릅니다.
- 지도에 배경 이미지가 없는 것은 현재 앱의 미구현 사항이며, 경로 데이터 자체가 없는 것은 아닙니다.
- 앱·브릿지 소스의 GitHub 업데이트만으로 NUC에 새 버전이 배포되거나 Android 앱이 자동 업데이트되지는 않습니다.
